## การจัดกลุ่มพันธุ์ต่อโรคใบด่าง (แก้ไขได้ที่ นำเข้าข้อมูล › พันธุ์ & ตั้งค่า)
- **ต้านทาน**: อิทธิ 1, อิทธิ 2, อิทธิ 3 (เพิ่มพันธุ์ใหม่ได้)
- **ทนทาน**: ห้วยบง 60, เกษตรศาสตร์ 50 (KU50)
- **อ่อนแอ**: ระยอง 11, CMR 89 / พันธุ์ 89, พันธุ์ไม่รับรอง/ไม่ระบุ (พันธุ์อื่นๆ, แขกดำ)
- **ค่อนข้างอ่อนแอ**: พันธุ์อื่นทั้งหมด

## การคุ้มครองข้อมูลส่วนบุคคล
- ไม่นำเข้าเลขบัตรประชาชน ชื่อ-สกุล ที่อยู่ เบอร์โทร เลขเอกสารสิทธิ์
- เว็บไซต์สาธารณะใช้ `data/parcels.js` แบบรวมกลุ่มตามกริด UTM 1 กม. (ไม่มีพิกัด/รูปแปลงรายแปลง)
- ข้อมูลรายแปลงละเอียดอยู่ใน `data/private/` (สร้างด้วย `--private`) ใช้บนเครื่องภายในเท่านั้น และถูกยกเว้นจาก git (`.gitignore`)
- ข้อมูลที่ผู้ใช้นำเข้าเก็บในเบราว์เซอร์ของเครื่องนั้นเท่านั้น

## เปิดใช้งาน

- ในเครื่อง: `python -m http.server 8765` แล้วเปิด http://localhost:8765 (จะใช้ข้อมูลรายแปลงละเอียดอัตโนมัติถ้ามี `data/private/`)

## อัปเดตข้อมูล
```
pip install pandas openpyxl shapely pyproj numpy scipy pillow pymupdf
python tools/build_ldd_soil.py          # ครั้งแรก หรือเมื่อ LDD ออกแผนที่ใหม่ (ดาวน์โหลด PDF อัตโนมัติ)
python tools/build_data.py              # ข้อมูลสาธารณะ (รวมกริด)
python tools/build_data.py --private    # + ข้อมูลรายแปลงสำหรับใช้ภายใน
git add -A && git commit -m "อัปเดตข้อมูล" && git push   # เว็บไซต์อัปเดตอัตโนมัติ
```
วางไฟล์ `ผังแปลงเกษตรกรรมดิจิทัล_*มันสำปะหลัง*.xlsx` และ `แบบรายงานภัยพิบัติ*.xlsx` ไว้ในโฟลเดอร์นี้หรือโฟลเดอร์แม่ (ไฟล์ .xlsx ไม่ถูก commit)
แก้ชื่อผู้พัฒนา/หน่วยงานได้ที่ `js/config.js` (`DEVELOPER`, `DEVELOPER_UNIT`)

## สูตรสำคัญ
- ผลผลิตเฉลี่ย (กก./ไร่) = ผลผลิตรวม (ตัน) ÷ เนื้อที่เก็บเกี่ยว (ไร่) × 1,000
- ดัชนีความเร่งด่วนจัดการโรคใบด่าง = 50 × สัดส่วนระบาด (เต็มที่ 5%) + 30 × สัดส่วนพันธุ์อ่อนแอ (ค่อนข้างอ่อนแอนับครึ่ง) + 20 × การขาดพันธุ์ต้านทาน/ทนทาน (เป้า 30%)
- ดัชนีรากเน่าโคนเน่า (รายแปลง) = 45 × (ปีที่ตำบลท่วม ÷ 7) + 35 × ข้อจำกัดดิน (S1 0, S2 0.3, S3 0.7, N 1, นอกพื้นที่ 0.4) + 20 × ปลูก พ.ค.–ก.ย. (1, อื่น 0.2)
- ความเสี่ยงรวม = 45% ระบาดใบด่าง + 25% การขาดพันธุ์ต้านทาน/ทนทาน + 30% ทับซ้อนน้ำท่วมซ้ำซาก
